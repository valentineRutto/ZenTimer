Privacy Policy

Effective date: July 27, 2026

Overview

Zen Timer Focus is a Chrome extension that provides focus timers, break timers, goals, ambient sounds, completion notifications, a New Tab experience, and a persistent Chrome side panel.

Information handled by the extension

Zen Timer Focus stores the following information locally on the user's device:

  • Focus-goal names created by the user
  • Time spent on each goal and the currently selected goal
  • Timer mode, duration, remaining time, and running or paused state

This information is stored using browser local storage and chrome.storage.local. It is used only to provide timer and goal-tracking functionality.

Zen Timer Focus does not collect browsing history, website content, search queries, credentials, email addresses, financial information, health information, precise location, or personal communications.

The Chrome side panel displays the extension beside the current webpage but does not read, modify, or transmit the contents of that webpage.

External audio requests

Zen Timer Focus connects only to https://assets.mixkit.co to stream user-selected ambient sounds and the timer-completion sound.

As with ordinary internet requests, Mixkit or its infrastructure may receive technical request information such as the user's IP address, browser user-agent, and request time. Zen Timer Focus does not control Mixkit's handling of this technical information. Review Mixkit's terms and privacy information for details.

No scripts or executable code are loaded from Mixkit.

How information is used

Locally stored information is used only to maintain timer state, resume paused sessions, track goal time, display completion notifications, and restore the extension interface.

The developer does not receive, view, sell, rent, or use this locally stored information for advertising, analytics, profiling, or marketing.

Information sharing

Zen Timer Focus does not transmit user-created goals or timer information to the developer and does not sell this information to third parties. The only external connection made by the extension is the HTTPS request to Mixkit required to stream ambient and completion sounds.

Chrome permissions

  • Storage: Saves timer and goal information locally.
  • Alarms: Keeps timer completion events reliable when the interface is closed.
  • Notifications: Alerts the user when a focus or break session finishes.
  • Side Panel: Displays the timer beside the current webpage.
  • Host access to assets.mixkit.co: Streams ambient and completion sounds.

Data retention and deletion

Timer and goal information remains locally on the user's device until the user deletes goals, resets the timer, clears the extension's stored data, or uninstalls the extension. Uninstalling Zen Timer Focus removes locally stored extension information according to Chrome's extension-storage behavior.

Data security

Zen Timer Focus does not operate a developer-controlled server or database for user information. External audio files are requested over encrypted HTTPS connections.

Chrome Web Store Limited Use

The use of information received from Chrome APIs adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements.

Zen Timer Focus does not use or transfer user information for personalized advertising, creditworthiness, lending, or unrelated purposes. The developer does not permit humans to read user information stored by the extension.

Children's privacy

Zen Timer Focus is not directed toward children under 13 and does not knowingly collect personal information from children.

Changes to this policy

This policy may be updated if Zen Timer Focus's functionality or data practices change. The effective date at the top of this page will be updated when revisions are published.
