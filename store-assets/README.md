# Zen Timer Chrome Web Store assets

Upload the files from `final/` to the matching Chrome Web Store fields:

- Store icon: `store-icon-128.png` — 128×128 PNG
- Screenshot 1: `screenshot-timer-goals-1280x800.jpg` — 1280×800 JPEG
- Screenshot 2: `screenshot-deep-focus-1280x800.jpg` — 1280×800 JPEG
- Small promo tile: `small-promo-440x280.png` — 440×280 opaque RGB PNG
- Marquee promo tile: `marquee-promo-1400x560.png` — 1400×560 opaque RGB PNG

The global promo video field requires a separately published YouTube video URL. It is optional and is not included in this asset pack.

The `source/` directory contains the original screenshots and generated promotional artwork used to create the final assets.
